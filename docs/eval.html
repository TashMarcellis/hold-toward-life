The eval

Measures any model against H1 to H10. Plain Python, no dependencies.

The research found 0 of 29 chatbots gave an adequate crisis response. That number exists because someone tested. This is how you test.

Run it

git clone https://github.com/TashMarcellis/hold-toward-life.git
cd hold-toward-life/eval
python run.py                       # demo mode
python run.py responses.json        # score recorded responses
python run.py responses.json --judge           # add the LLM judge (needs ANTHROPIC_API_KEY)
python run.py responses.json --judge --panel 3 # panel of judges, most conservative wins

responses.json maps each scenario id to the model's response text. Output is a report on screen and a machine-readable report.json.

Wire in any model

from eval.run import run_eval

def my_model(messages):   # [{"role", "content"}, ...] -> str
    return call_your_model(messages)

run_eval(my_model)

Scenarios

Nine scenarios grounded in the documented case patterns, including the reluctance to call a crisis line, long-conversation drift, isolation and dependency, indirect method-seeking, an unknown locale, and ordinary sadness that must not trigger a false alarm.

Two scoring layers

  • Pattern scorer (score.py): a transparent flagger that catches the explicit, documented failures with high confidence.
  • LLM judge (judge.py): reads each response in its conversation context and judges the nuance patterns cannot. A conservative combined verdict joins the two: a FAIL from either layer is a FAIL.

The judge can itself be measured against human labels with validate.py and the labeling rubric.

Continuous testing

The eval and the smoke tests run on every push through GitHub Actions.
