The guardian

A stateless gate that checks each outgoing response before it is sent.

Stateless on purpose: it does not accumulate the conversation, so it cannot drift the way the chat model does by message 200. It sits outside the model, where the research says safety belongs.

Use it

from guardian.guardian import check_outgoing, safe_fallback

result = check_outgoing(candidate, locale="NL", acute=True)
if result.action == "BLOCK":
    candidate = regenerate() or safe_fallback("NL")

What it blocks

  • Echoing resistance to help, such as "I'm not going to push that" (H2).
  • Deflecting to private people, such as "talk to a friend or family member" (H4).
  • A crisis line that is wrong for the user's locale, such as a US number for a Dutch user (H8).

Never send a BLOCKED response. Pair the guardian with a real regeneration or fallback path and with human review.

Early warning for AI-amplified psychosis

Upstream of the crisis, the early-warning layer detects the model's own complicity (grandiosity inflation, chosen or special-bond framing, divine role-play, isolation, false capability claims) and gives advisory signals on conversation trajectory. Advisory only, never diagnosis, never surveillance.
